To permanently remove items from source code:

  1. Delete items normally using X button in the app
  2. Click "Export Deleted IDs to File" above
  3. Copy the JSON output
  4. Create a file called deletedItems.json in project root
  5. Paste the JSON into that file
  6. Run: node scripts/cleanDeletedItems.js
